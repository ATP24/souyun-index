# 🧪 测试套件说明 (Test Suite)

本目录包含 `souyun-index` 的端到端自动化测试脚本，所有脚本均基于真实服务端口进行黑盒与灰盒检验。

---

## 📋 测试清单

| 脚本文件 | 测试目标 | 涵盖场景 |
| :--- | :--- | :--- |
| **`test_all_v2.py`** | 全功能端到端集成检验 | 1. 历代名家汇评集释 (Comments) 提取；<br/>2. 原典前后文载录语境 (Context) 完整性；<br/>3. 古籍实体多页跨页连续书影 (Images) 数组与首尾叶校验。 |
| **`test_fix_500.py`** | 极端字符容错与连接池长连接性能 | 1. 纯文本检索；<br/>2. Unicode 隐形特殊空白（全角空格 `\u3000`、零宽空格、换行符）容错；<br/>3. 末尾句号、叹号、问号、书名号等敏感标点容错；<br/>4. 连接池异步预热首发 0.06s 极速响应。 |
| **`test_features_1_2.py`** | 语境与汇评双核心验证 | 验证语境及汇评字段结构与前后文命中下划线标记。 |
| **`test_heartbeat.py`** | 服务生命周期与心跳守护 | 验证无死锁异步生命周期与失活退出。 |

---

## 🚀 运行方法

在项目根目录下执行：

```bash
# 执行全功能集成测试
python tests/test_all_v2.py

# 执行字符容错与连接池测试
python tests/test_fix_500.py
```
